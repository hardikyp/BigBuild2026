# MORGAN database migrations

The application records applied schema versions in the SQLite `schema_migrations` table. `001_initial` creates the SQLAlchemy domain tables and is applied automatically when the local database is first opened. `002_evidence_report_flag` adds `evidence.include_in_report` (default true) so reviewers can choose which photos appear in the PDF report; existing evidence rows are kept and default to included. `003_drawing_interpretations` adds the `drawing_interpretations` table, which records each run of reading uploaded plans and elevations into intake fields: the model used, the evidence rows holding the drawings, every interpreted value with its confidence and basis, and which fields were applied or left as the engineer had them. Future schema changes should add a new numbered migration and preserve existing assessment data.
